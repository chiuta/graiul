## [0.2.0] - 2026-11-17

### Added
- The engine in `src/engine.mjs`: search without regard to diacritics with ranking, validation of entries, identical and very similar entries, the proverb of the day, per-county counts, TSV export, the contribution file and the parser for pasted lists.
- TSV export for spreadsheets: a cell that starts with `=`, `+`, `-` or `@` gets an apostrophe in front, so that Excel or LibreOffice does not run it as a formula (a text that really starts with `-` therefore shows an apostrophe in the sheet). The file the page downloads also starts with a UTF-8 byte-order mark, so that the diacritics show correctly.
- The interface in `src/ui.js`, `src/i18n.mjs` and `src/app.css`: search, proverb of the day, county map, add (one entry or many at once), export, import and guide; eight languages, dark and light themes, keyboard, works from 360 px wide, and the map has a fallback layout for browsers without CSS Grid.
- Care for keyboard and screen-reader users: the focus is never lost (after «Show all counties» it moves to the tile of the county that was selected; after changing the reliability in the add form it stays on that field), «More details» stays open when you change the type, and the language and region filters go back to «All languages» and «All regions» when the last entry with that value is removed.
- When something goes wrong the page says so and keeps your work: the lines that «Add many at once» rejects stay in the box, each with its line number and reason; if the browser has no room to store entries, adding and importing are undone and an error is shown instead of reporting them as saved; saved state with hostile or invalid values (an id such as `__proto__`, an unknown language, county, licence or consent, over-long fields) is cleaned when the page starts and never reaches the form.
- The search for duplicates stays fast on large files: each text is analysed once, only pairs of similar size are compared and the comparison stops as soon as the threshold can no longer be reached, with exactly the same results as the plain definition (tested); importing a file of several megabytes no longer stalls the page.
- Data: 10 Romanian proverbs with their sources (the English equivalents taken from Wikiquote are marked CC BY-SA 4.0), the county tiles `data/counties.json` and a stricter `schema.json` (types, `answer`, `purpose`, `consent`, `county`, `translations`, `status`, `license`).
- `scripts/validate.py`: checks every file against its schema and the rules a schema cannot express (file name, county tiles, `sourced` and `reviewed`, consent, duplicates); `scripts/import_bundle.py` turns the contribution file made by the page into data files; `scripts/potd.mjs` writes the proverb of a date as a static page.
- `docs/contributor-guide.md` and `docs/collecting-guide.md` (also in Romanian): how to add entries and how to collect folklore ethically (consent, attribution, what not to publish).
- Tests: `npm test` (the engine, the data, the Python scripts, the proverb-of-the-day script, the build and the interface texts) and browser tests in the hub (eight languages, accessibility, hostile stored state, import and export, small screens).
- `src/` and `scripts/build.mjs`: the single `index.html` is now built from the sources, with the data embedded, and `--check` verifies it.
- ISSUES_GOOD_FIRST and CODE_OF_CONDUCT translated into all eight languages.
- README in English, Romanian, French, Italian, Spanish, Portuguese, German and Hungarian: status and planned scope sections (derived from `ISSUES_GOOD_FIRST.md`).
- Installable (PWA): `manifest.webmanifest`, `sw.js` and icons generated by the shared kit (`fff-kit/pwa`); the page works offline after the first visit over HTTPS.

### Changed
- The workflow runs on Ubuntu 26.04 with Node.js 26 and also runs the tests, the build check and the data validation.
- `schema.json` rejects unknown fields and now describes the types, `answer` for riddles, `purpose` for charms, `consent` for charms and anything with a `collector`, `county`, `translations`, `source_url`, `license`, `status` and `reviewed_by`.
- The README no longer lists a planned scope: it describes what the page does and what it does not do yet.
