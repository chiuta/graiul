# Bonnes premières tâches

[English](ISSUES_GOOD_FIRST.md) · [Română](ISSUES_GOOD_FIRST.ro.md) · **Français** · [Italiano](ISSUES_GOOD_FIRST.it.md) · [Español](ISSUES_GOOD_FIRST.es.md) · [Português](ISSUES_GOOD_FIRST.pt.md) · [Deutsch](ISSUES_GOOD_FIRST.de.md) · [Magyar](ISSUES_GOOD_FIRST.hu.md)

- [ ] Ajouter 50 proverbes de votre propre région, avec `region` renseigné jusqu’au département (județ)
- [ ] Ajouter 20 devinettes avec leurs réponses dans un champ `answer` (étendre le schéma)
- [ ] Ajouter 10 incantations avec un champ `purpose` et une source ethnographique
- [ ] Ajouter 10 chants de Noël — uniquement des textes traditionnels ou du domaine public
- [ ] Ajouter des entrées hongroises de Roumanie (lang hu, région Transylvanie)
- [ ] Ajouter des traductions en français des 50 proverbes les plus courants
- [ ] Construire une vue cartographique (région -> éléments) avec un GeoJSON local
- [ ] Ajouter un générateur statique de page « proverbe du jour »
- [ ] Ajouter un détecteur de doublons fondé sur le texte normalisé
- [ ] Rédiger des lignes directrices pour collecter le folklore avec éthique (consentement, attribution)

Créez-les toutes sur GitHub avec `scripts/create_issues.sh` (nécessite la CLI `gh`).
