# Sarcini bune pentru început

[English](ISSUES_GOOD_FIRST.md) · **Română** · [Français](ISSUES_GOOD_FIRST.fr.md) · [Italiano](ISSUES_GOOD_FIRST.it.md) · [Español](ISSUES_GOOD_FIRST.es.md) · [Português](ISSUES_GOOD_FIRST.pt.md) · [Deutsch](ISSUES_GOOD_FIRST.de.md) · [Magyar](ISSUES_GOOD_FIRST.hu.md)

- [ ] Adaugă 50 de proverbe din propria regiune, cu `region` completat până la nivel de județ
- [ ] Adaugă 20 de ghicitori cu răspunsuri într-un câmp `answer` (extinde schema)
- [ ] Adaugă 10 descântece cu un câmp `purpose` și sursă etnografică
- [ ] Adaugă 10 colinde — doar texte tradiționale sau din domeniul public
- [ ] Adaugă intrări maghiare din România (lang hu, regiunea Transilvania)
- [ ] Adaugă traduceri în franceză pentru cele mai răspândite 50 de proverbe
- [ ] Construiește o vizualizare pe hartă (regiune -> intrări) cu un GeoJSON local
- [ ] Adaugă un generator static pentru pagina „proverbul zilei”
- [ ] Adaugă un detector de duplicate pe baza textului normalizat
- [ ] Scrie un ghid pentru culegerea etică a folclorului (consimțământ, atribuire)

Creează-le pe toate pe GitHub cu `scripts/create_issues.sh` (cere CLI-ul `gh`).
