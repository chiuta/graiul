# Gute erste Aufgaben

[English](ISSUES_GOOD_FIRST.md) · [Română](ISSUES_GOOD_FIRST.ro.md) · [Français](ISSUES_GOOD_FIRST.fr.md) · [Italiano](ISSUES_GOOD_FIRST.it.md) · [Español](ISSUES_GOOD_FIRST.es.md) · [Português](ISSUES_GOOD_FIRST.pt.md) · **Deutsch** · [Magyar](ISSUES_GOOD_FIRST.hu.md)

- [ ] 50 Sprichwörter aus der eigenen Region hinzufügen, mit `region` bis auf Kreisebene (județ) ausgefüllt
- [ ] 20 Rätsel mit Antworten in einem Feld `answer` hinzufügen (Schema erweitern)
- [ ] 10 Zaubersprüche mit einem Feld `purpose` und ethnografischer Quelle hinzufügen
- [ ] 10 Weihnachtslieder hinzufügen — nur traditionelle oder gemeinfreie Texte
- [ ] Ungarische Einträge aus Rumänien hinzufügen (lang hu, Region Siebenbürgen)
- [ ] Französische Übersetzungen der 50 häufigsten Sprichwörter hinzufügen
- [ ] Eine Kartenansicht (Region -> Einträge) mit lokalem GeoJSON bauen
- [ ] Einen statischen Generator für die Seite „Sprichwort des Tages“ hinzufügen
- [ ] Einen Duplikatdetektor auf Basis normalisierten Textes hinzufügen
- [ ] Leitlinien zum ethischen Sammeln von Folklore schreiben (Einwilligung, Namensnennung)

Lege sie alle auf GitHub mit `scripts/create_issues.sh` an (benötigt die `gh`-CLI).
